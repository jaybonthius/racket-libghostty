# Selection and tracked-grid-reference prior art

The behavioral authority is pinned Ghostty commit `51ed437cd1a202e625feb7fd0577354d81bcc54b`. `include/ghostty/vt/point.h`, `grid_ref.h`, `grid_ref_tracked.h`, `screen.h`, `selection.h`, and `terminal.h:1988-2082` define coordinates, borrowed grid references, owned tracked references, copied cell/row queries, selections, and terminal resolution. Matching implementation lives in `src/terminal/c/{grid_ref,grid_ref_tracked,selection,terminal}.zig`, `src/terminal/{Selection,Screen}.zig`, and the page-list implementation.

`GhosttyGridRef` is an unowned sized snapshot valid only until the next terminal mutation. The Racket API never publishes it: point resolution, selection derivation, tracked snapshots, and cell/row/style/grapheme/hyperlink copying all finish under one terminal lock. `GhosttyPoint` accepts active, viewport, screen, and history coordinates; screen/history resolution may traverse scrollback. Invalid or out-of-range points report `GHOSTTY_INVALID_VALUE`, while a valid reference that cannot be expressed in a requested space reports `GHOSTTY_NO_VALUE`.

`GhosttyTrackedGridRef` is caller-owned, follows scroll, reflow, and remappable pruning, and becomes no-value after destructive loss or terminal free. It remains freeable after terminal destruction and can be restored with `set`; native `set` preserves its old value on allocation failure. The Racket wrapper strongly retains its terminal while open, serializes every operation through that terminal's semaphore, supports idempotent explicit close and exactly-once finalizer cleanup, but does not prevent explicit terminal close. Point and snapshot operations return copied immutable values or `#f`; snapshot copying uses the tracked handle's owner screen even while that screen is inactive.

A native `GhosttySelection` contains directional inclusive borrowed endpoints and a rectangle flag. Terminal option `GHOSTTY_TERMINAL_OPT_SELECTION` copies it into terminal-owned tracked state; terminal data `GHOSTTY_TERMINAL_DATA_SELECTION` returns another mutation-invalidated snapshot. Word, word-between, line, all, and semantic-output derivations do not install their result. Racket derives and installs in one locked transaction, exposes only copied screen-coordinate state, and maps no selectable content to `#f` without replacing an existing selection.

Pinned Ghostty loses a tracked pin's `garbage` bit when converting terminal selection state back to `GhosttyGridRef` (`src/terminal/c/selection.zig:32-37` and `grid_ref.zig:23-40`). A deterministic 20,000-line prune still makes raw selector 31 and both endpoint-to-screen conversions report success at retargeted coordinates. Racket therefore owns two additional private tracked endpoints for each public installation, validates their value, screen, direction, rectangle, and agreement with the native getter before selection observation or render, and clears mismatched native state. Reset and terminal teardown release the private endpoints; writes and resize let both native and private pins move.

Selection plain-text formatting uses Ghostty allocation and always frees the returned pointer with `ghostty_free` and the exact observed length. `#f` distinguishes no active selection from a present selection that formats to immutable `""`. Defaults enable unwrap and trim. Custom word-boundary and line-whitespace strings are copied as Unicode scalar arrays; `#f` requests native defaults and `""` passes a distinct non-null zero-length override.

Go exposes borrowed `GridRef`, owned `TrackedGridRef`, the complete borrowed `Selection`, buffer and allocated formatting, adjustment/order/ordered/contains/equality, and owned gesture/event families (`/home/jay/Code/go-libghostty/{grid_ref.go,grid_ref_tracked.go,selection.go}`). Its tests cover invalid creation, movement, reset/loss/rebind, terminal-close-first, repeated close, selection derivation/formatting/order/containment, and gesture interaction (`grid_ref_test.go:66-214`, `selection_test.go:9-400`). Racket adopts the failure and lifetime cases but rejects Go's retained borrowed references, generic getters, and unsafe terminal/ref composition.

Rust ties `GridRef` and `Selection` to terminal lifetimes, stores terminal identity in `TrackedGridRef`, maps lost tracked positions to `Ok(None)`, and frees owned references through `Drop` (`/home/jay/Code/libghostty-rs/crates/libghostty-vt/src/{screen,terminal,selection}.rs`). Tests cover scroll, reset/loss/rebind, terminal drop, and wrong-terminal rejection. Racket instead hides untracked values completely and remembers the creating terminal inside the owned handle, making wrong-terminal pairing impossible at the public seam.

Python's curated `Terminal.text` and `contents` derive and immediately copy text rather than publish references (`/home/jay/Code/pyghostty/core.py:46-90`); generated declarations include tracked references but no comparable owned workflow. Exact-name searches found no maintained selection/tracked-reference workflow in the local Node binding. The Go browser spike demonstrates gesture routing, copy-on-release, wide-tail rendering, mouse-tracking override, and viewport behavior (`/home/jay/Code/worktrees/shux/libghostty-poc/spikes/libghostty-terminal/{selection_copy_test,viewport_test}.go`), but the Racket browser currently lacks native viewport movement and honest autoscroll policy.

All operations touching a terminal use its existing semaphore and callback policy: same-terminal callback calls fail immediately, while cross-terminal callback acquisition is nonblocking. Constructors mask breaks only after lock acquisition across ownership transfer; close, mutation publication, allocated formatting cleanup, private endpoint replacement, reset, and terminal release are break-safe. No second tracked lock exists, so this facility adds no lock-order cycle.

Public tests cover all coordinate spaces and invalid bounds; copied grapheme, hyperlink, style, cell, and row values; active and inactive screen owners; scroll/reflow movement, destructive pruning, reset, rebind, close order, rooting, and finalizers; direct, reversed, rectangular, word, word-between, line, semantic-output, and all selections; formatting, Unicode, order, containment, adjustment, rendering, reset, screen switching, snapshot omission, garbage-pin validation, breaks, close races, and callback lock behavior. One public workflow derives semantic output, observes render selection and copied text, follows a tracked cell through scrolling, then clears and closes.

Gesture/event ownership, repeat timing, pixel geometry, autoscroll, and browser pointer routing form a separate coherent facility and are deferred. VT/HTML formatting, caller buffers, custom allocators, ordered-copy, equality, generic get/multi-get, and raw cell/row/reference values add no capability required by this curated slice and remain private or unbound.
